# My agent: Enterprise AI Search & Knowledge Discovery

One-liner: A semantic search and RAG knowledge agent that indexes enterprise documentation, summarizes complex internal technical guides, and provides structured search result cards with citations.

Tool coverage:
- Memory: Remembers user search filters, role-based access preferences, recent queries, and bookmarked documentation topics.
- Tools: Enterprise document search, vector RAG retrieval, document summarization, filter by department/file-type, public web knowledge fallback.
- Catalog/UI: Search result cards, document preview modals, source citation cards, and relevant topic pills.
- Image gen: Generates architecture flowcharts and data flow diagrams for searched engineering topics.
- Sandbox: Parses raw text/log dumps (.txt, .md, .log) and extracts structured key-value metrics.
